Privacy & Security Built In

We take security seriously. That's why Sebastian is read-only by architecture, not by policy.

  • No write operations allowed - guaranteed by code design
  • No delete operations - files always safe
  • No code execution - terminal stays protected
  • Sandboxed file access - only allowed directories
  • Complete audit trail - every action logged
  • Open source - inspect the code yourself
