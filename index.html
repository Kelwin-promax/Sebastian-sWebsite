FAQ

Common questions

What's the difference between Local and Cloud? expand_more
Local runs everything on your computer (private but slower ~100s). Cloud uses Claude API (fast ~2-3s but requires internet).
Do I need an API key? expand_more
Only for Cloud mode. Local mode doesn't require one. Get a free key at console.anthropic.com.
Does it work offline? expand_more
Yes, completely! In Local mode (Ollama). Cloud mode requires internet for each request.
How much does it cost? expand_more
Local is completely free. Cloud: pay only for usage (typically cents per query).
Can I change modes later? expand_more
Yes! Run python sebastian.py --setup to reconfigure anytime.
